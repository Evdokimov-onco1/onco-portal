## Архитектура и фактические ограничения

Tilda отвечает за страницы и Members. Тонкий T123-блок загружает один движок `src/portal.js`, стили и JSON из собственного GitHub/CDN; `data-year` выбирает учебный год. Word находится в `modules/`. В новой версии семь панелей: модули, библиотека, тесты, VP, OSCE, Tumor Board, календарь. Выбор архитектуры зафиксирован в `docs/ADR-001-data-and-engine-on-github.md`.

Сохранённые T123 используют `@main`; `data-results-url` пустой. План выпуска по тегам в старом README не доказывает, что теги уже установлены на страницах. Main используется тестовыми страницами через CDN: слияние имеет последствия для загружаемого кода. Реальные вставки, CSS/JS/JSON/Word и откат сверять перед выпуском.

Прогресс чтения ещё не реализован; существующий localStorage читает профиль Members. Общий приёмник результатов не подключён. При настройке URL текущий no-cors POST не подтверждает сохранение на сервере; сообщение интерфейса об отправке не является доказательством доставки. Межустройственную синхронизацию не обещать.

Репозиторий и учебные ответы публичны. Tilda Members не скрывает публичные JSON/Word. Права GitHub и редактора Tilda различаются; приглашение коллеги в GitHub не выдаёт роль в Tilda.
