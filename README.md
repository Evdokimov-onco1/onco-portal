# ONCO — портал ординатуры кафедры онкологии

Проект для М.Ю. Федянина и Владимира Евдокимова. Сайт: https://onco-science.ru/ . Репозиторий содержит действующую учебную базу, движок, материалы и полный пакет для совместного продолжения работы.

**Начните с [передачи проекта](docs/HANDOFF.md).** Коллеге достаточно этого файла и [инструкции запуска](docs/DEVELOPMENT.md). Для ИИ-ассистента: [HANDOFF_AI.md](docs/HANDOFF_AI.md) и [AGENTS.md](AGENTS.md).

## Точка продолжения на 4 октября 2026 года

Новый портал уже разработан и ранее опубликован на тестовых страницах Tilda. Последние приоритеты Владимира от 22 сентября: сделать новую версию доступной ординаторам, разделить карточку модуля на части, сохранять прогресс и исправить ссылки на конкретные видео.

База V4 содержит **61 модуль, 633 вопроса, 12 виртуальных пациентов, 12 OSCE, 8 Tumor Board и 63 занятия календаря**. Модули распределены на 34 темы первого года и 27 второго. Клиническая актуальность не следует из структурной проверки.

Ветка передачи `handoff/2026-10-04` восстановлена поверх GitHub main `169da9c`. В ней собраны изменения пяти локальных коммитов до `3a2c461` и материалы передачи. При сборке пакета `main` и страницы Tilda не изменялись. Слияние этой ветки обновит файлы, которые тестовые страницы получают из `main` через CDN; это отдельный шаг, требующий приёмки. Подробности и точные границы проверки: [VERIFICATION.md](docs/VERIFICATION.md).

## Быстрый запуск

```sh
git clone https://github.com/Evdokimov-onco1/onco-portal.git
cd onco-portal
git switch handoff/2026-10-04
python3 tools/verify_handoff.py
python3 -m http.server 8787 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8787/dev/index.html?year=1 . На Windows вместо `python3` можно использовать установленный `python` или `py -3`. Установка npm-пакетов для запуска портала не нужна.
