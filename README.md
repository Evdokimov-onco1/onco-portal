# onco-portal

Раздел «Ординатура» сайта кафедры онкологии ФГБУ НМХЦ им. Н.И. Пирогова: https://onco-science.ru
(Tilda, проект 17587206). Данные и движок портала живут здесь, в Tilda стоит тонкий блок T123,
который подгружает их через jsDelivr. Почему так: [docs/ADR-001](docs/ADR-001-data-and-engine-on-github.md).

## Структура

```
data/      orp-data.json — собранная база (V4): модули с блоком «что читать», банк v34, календарь, библиотека, VP, OSCE, TB
modules/   61 DOCX-модуль stage6 и календарный план; раздаются через raw.githubusercontent.com (jsDelivr отдаёт 403 на DOCX)
src/       portal.js (движок, сам строит разметку) и portal.css
tools/     build_data.py — сборка базы из JSON руководителя + stage6 (банк v34, DOCX→md, index.html)
           check_data.py — проверка базы (форматы ID, висячие ссылки, покрытие)
dev/       index.html — локальная проверка: python3 -m http.server 8787, затем /dev/index.html?year=1
tilda/     PAGES.md (карта страниц), T123-year-1.html и T123-year-2.html (что вставлять в блок), снимок экспорта
docs/      аудит и план, ADR, транскрипт постановки задачи
archive/   пакет руководителя V4 (исходник) и снимок живой сборки сентября 2026
```

## Откуда что взято

- `data/orp-data.json` — файл `ONCO_RESIDENCY_PORTAL_DATA_V3_INTERACTIVE.json` из пакета руководителя
  от 31.08.2026. Совпадает байт в байт с тем, что сейчас грузит сайт.
- `archive/supervisor-package-v4/` — монолит и вспомогательные страницы руководителя; из монолита
  вынесены `portal-markup.html`, `portal.css`, `portal-engine.js`.
- `archive/live-2026-09/` — движок из репозитория исполнительницы и заметки о живом блоке.

## Релизы

Блок в Tilda ссылается на файлы по тегу: `https://cdn.jsdelivr.net/gh/Evdokimov-onco1/onco-portal@v1.0.0/...`.
Ветка `main` для разработки, тег для публикации. После смены тега jsDelivr отдаёт новую версию сразу.

## Как устроен блок в Tilda

В T123 вставляется только контейнер с настройками, ссылка на CSS и на JS (см. `tilda/T123-year-*.html`).
Движок читает `data-year`, `data-data-url`, `data-results-url`, `data-home`, сам рисует шесть панелей
(модули, библиотека, тесты, виртуальные пациенты, OSCE, Tumor Board) и понимает глубокие ссылки
`?module=M07`, `?vp=VP-01`, `?osce=S01`, `?tb=TB01`, `?panel=tests`.

Карточка модуля собирается из связей в данных: лекция, что читать (КР РФ, учебники, источники к вопросам),
семинар и задачи, вопросы для разбора, тест по модулю, практика (VP / OSCE / TB с переходом), инструменты и симуляторы.

## Пересборка данных

DOCX сначала переводятся в Markdown (`~/.local/bin/to-md stage6/М-*.docx`), затем:

```
python3 tools/build_data.py --stage6 ../stage6
python3 tools/check_data.py
```

Источники записаны в `data/orp-data.json` → `sources`. Банк вопросов берётся только из v34,
блок А (рекомендации, обзоры, ключевые исследования, лекции), задачи Б2 и чек-листы Б3 — из DOCX.
