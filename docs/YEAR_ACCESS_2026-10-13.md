# Доступ к годам обучения, 13.10.2026

По новому поручению: все модули первого года открыты в любом порядке.
Второй год полностью закрыт до действующего итогового зачёта последнего модуля
первого года преподавателем. После зачёта весь второй год открыт без цепочки.
В каноническом каталоге последний модуль первого года — M60; номера годов
перемешаны. Условие вычисляется по каталогу, номер не зашит в код доступа.

Установлено на Timeweb: `release-year-gate-20261013T123621Z/app`.
Откат: `backups/before-year-gate-20261013T123621Z/app.py` содержит прежнюю
WSGI-точку входа. Выпуск скопирован с действующего кода регистрации; изменены
только `pilot/server.py` и `pilot/web/learning.js`. Базы и SMTP-конфигурация
не перезаписывались. Исходники сохранены локально в ветке `fix/year-two-gate`;
публикация этой ветки на GitHub не выполнялась.

Проверено: четыре HTTP-теста правил доступа, блокировка чтения/записи, старых
тестов и ответов через прямые API, изоляция учащихся, реальный учебный зачёт
на синтетической базе и повторная блокировка при утрате действующего зачёта.
Node-проверка каталога и страниц, замок на переключателе второго года,
карточки без прямых ссылок и новые пояснения. На сервере проверены все 61
модуля с изолированной временной базой и открытие второго года после зачёта
M60; действующие ответы не использовались для тестовых записей.

Работающий сайт отвечает HTTP 200 и отдаёт новый learning.js.
Браузер показывает вход: визуальная приёмка под аккаунтом учащегося
не выполнена; проверка UI выше — автоматическая, не браузерная.
