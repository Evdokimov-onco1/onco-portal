# Полный состав модуля: материалы и сохраняемый тест

10.10.2026. Рабочая ветка `feat/module-learning-content`, основана на `feat/local-learning-pilot` (PR №4). Это продолжение локального пилота на 8789. Tilda и main не изменялись. Предыдущие `/dev/` и test-v2 не получают этот серверный код автоматически.

## Запуск для коллеги

```sh
git fetch origin
git switch feat/module-learning-content
python3 -m unittest pilot.test_store pilot.test_quiz pilot.test_server
python3 -m pilot.server --port 8789 --db /tmp/onco-learning-pilot/pilot.sqlite3
```

Открыть http://127.0.0.1:8789/ . Python 3.10+, только стандартная библиотека. Если порт занят своим предыдущим пилотом, остановить его и перезапустить с тем же путём базы. Не использовать `python -m http.server`: он не реализует API и может раскрыть исходный банк. Демо-доступы: student-a / demo-student-a, student-b / demo-student-b, teacher / demo-teacher. Вводить только вымышленные ответы. SQLite не добавлять в Git; для постоянной локальной работы выбрать путь вне репозитория и временного каталога.

## Реализовано

- Во всех 61 модулях единая навигация: лекция и чтение, задачи, тест, семинар, OSCE/Tumor Board, инструменты, прогресс.
- Материалы берутся из `data/orp-data.json` без переписывания медицинского содержания. Рекомендации, обзоры, исследования, обновления и видеоархивы разделены. Пустые ссылки показаны как отсутствующие.
- Кафедральные видеокарточки берутся из ранее собранного `docs/audit-2026-10-10/FACULTY_VIDEO_CATALOGUE.csv`. Это предварительное тематическое сопоставление, не подтверждение преподавателя или воспроизведения. У M01 точной кафедральной записи в этом сопоставлении нет; у M27 есть кандидаты. Общие архивы не засчитываются как конкретная лекция.
- Открытия разрешённых ссылок сохраняются отдельно для каждого ординатора и версии списка. Открытие не доказывает изучение. Произвольный URL с клиента не принимается.
- Задачи сохраняют прежнюю историю ответов и проверок. Эталон выдаётся после отправки собственного ответа. Полный Word с эталонами запрещён студентам на сервере; путь `/documents/Mxx` доступен только назначенному преподавателю.
- Тест включает все вопросы выбранного модуля. Порядок и копия банка фиксируются на момент старта, каждый выбор сохраняется в SQLite, незавершённую попытку можно продолжить после повторного входа/перезапуска. До завершения API не выдаёт ключи и объяснения.
- Итог рассчитывается сервером по точной доле: `score * 100 >= total * 70`. До ответа на все вопросы завершить нельзя. Повторная попытка новая; завершённая неизменяема, прежние остаются в истории. Правильные ответы и объяснения показываются после завершения.
- Преподаватель видит результаты по назначенным ему модулям. Демо-преподавателю назначены все модули; это не назначение реальных лекторов проверяющими.

## Что пока не завершено

Вопросы к семинару, описания назначенных OSCE/TB, виртуальные пациенты, инструменты и чек-листы доступны для подготовки. Письменная сдача этой практики и журнал семинаров пока не реализованы. Этапы TB и эталоны OSCE заранее студентам не раскрываются. Отсутствующая связь OSCE/TB помечена как пробел, а не исключение, разрешённое Федяниным.

Нет итоговой кнопки завершения модуля. Экран прогресса пока информационный: он не выставляет зачёт и не подменяет подтверждение преподавателя. При изменении банка отдельно потребуется политика актуальности старого тестового результата. Реальная регистрация шести ординаторов, назначение преподавателей, production-авторизация и публикация остаются в плане.

## Проверено

45 автоматических проверок: 14 для письменных ответов, 19 для QuizStore, 12 HTTP. В том числе одновременный save/submit, изоляция пользователей, ограничение преподавателя назначенными модулями, перезапуск, история повторных попыток, 7/10 pass, 16/23 fail без округления, защита от клиентского score/identity и прямого Word-доступа. Синтаксис обоих JS проверен Node.

`tools/verify_handoff.py`: 131 контрольная сумма исходников сохранена; 61 модуль, 633 вопроса; пересборка совпадает с V4. Это проверка целостности, а не медицинская экспертиза.

В браузере: M01 — материалы, семинар, инструменты, сохранение одного ответа и возобновление после reload, полный технический тест со всеми ответами A (3/10), просмотр результата преподавателем. M11 — две OSCE и восемь TB. M27 — кафедральные видеокандидаты. История ранее проверенных задач сохранилась. Проверена узкая страница 340 px без горизонтального переполнения документа; навигация прокручивается внутри своей строки. Проверка всех ссылок и реальных мобильных устройств не выполнена.
