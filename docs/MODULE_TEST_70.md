# Зачётный тест модуля (порог 70%)

Реализовано в `src/portal.js` (`setupTests`). Два режима банка тестов:

- **Зачёт модуля.** При выборе конкретного модуля в панели «Банк тестов» или при запуске
  из карточки модуля («Самоконтроль» → «Запустить тест по модулю») задаются **все** вопросы
  модуля, каждый ровно один раз (порядок перемешивается). Переключатель количества при этом
  скрывается — сокращённого зачёта нет. Зачёт выставляется, если `score*100 >= total*70`
  (сравнение до округления процента; для 16 вопросов нужно минимум 12 верных, для 23 — 17).
- **Тренировка «Все модули».** Случайная выборка 5/10/20/60 из всего банка. Помечается как
  тренировка и не засчитывается как зачёт модуля.

Перед стартом показывается экран с правилом режима и кнопкой «Начать»; под контролами
панели постоянно видна подсказка о текущем режиме. В результате выводятся счёт, процент,
вердикт «Тест зачтён» / «Тест не зачтён», порог и необходимое число верных ответов.
Смена режима в контролах синхронизирует подсказку и видимость счётчика, но не прерывает
уже идущую попытку. «Пройти ещё раз» запускает тот же банк заново со сброшенным счётом;
очки начисляются один раз за вопрос (повторный клик по ответу игнорируется).

**Ограничения:** результат — самопроверка. Сохранение истории, приёмник результатов и
подтверждение преподавателем в этой версии не подключены и интерфейсом не обещаны;
модуль целиком зачтённым не объявляется. Пустой банк обрабатывается сообщением без
расчёта процента.

## Проверка

```bash
node --test tools/test_module_quiz.cjs
```

Тест выполняет реальную функцию `setupTests` из `src/portal.js` в Node `vm` с минимальными
заглушками элементов: реальный банк M05 (16 вопросов) из `data/orp-data.json` плюс
синтетические модули. Покрывает: обе точки запуска, 16 вопросов без дублей, 11/16 —
не зачтён, 12/16 и 7/10 — зачтён, 16/23 — не зачтён при округлении до 70%, повторную
попытку, пустой банк, смешанную тренировку и защиту от двойного клика.
