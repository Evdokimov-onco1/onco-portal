# Обзор кафедральных лекций для преподавателя

10.10.2026 · ветка `feat/lecture-coverage` поверх `feat/module-completion` (PR №7). Локальный пилот; `main` и Tilda не меняются.

Войти как демонстрационный преподаватель → «Завершение модуля». Над формой привязки появился общий обзор доступных преподавателю модулей: количество привязанных, с кандидатами и без кандидатов. Фильтр статуса и поиск по коду/названию работают совместно. «Привязка» переводит фокус к форме выбранного модуля. Новых автоматических привязок нет.

В исходном каталоге 61 модуль: 15 с предварительными кандидатами, 46 без них. Это не означает, что для 46 модулей лекций не существует — пока отсутствует сопоставление. «Привязана» означает связь с текущей редакцией материалов, а не зачёт модуля или проверенное воспроизведение. Преподаватель должен открыть запись, проверить соответствие и явно подтвердить привязку.

## Контракт и сохранность

`GET /api/completion/lectures` доступен только преподавателю и перечисляет только назначенные ему модули. Возвращает `summary` и `modules`; не возвращает ответы ординаторов или эталоны. Чтение не создаёт привязок. Связь с прежней версией материалов перестаёт считаться актуальной; история в SQLite сохраняется. Схема БД и критерии зачёта не изменены. OSCE необязателен, тест по всем вопросам с порогом 70%.

Ошибка загрузки обзора или формы отображается как ошибка с повтором, а не как отсутствие лекций. Устаревшие ответы после смены роли/вкладки не применяются; предупреждение о несохранённой привязке сохраняется. Поиск не заменяет свой input при вводе. Список ограничен по высоте и доступен с клавиатуры.

Cursor / Composer2.5 реализовал API, интерфейс, тесты и исправление фокуса. Devin / SWE-2 High написал независимые HTTP-тесты и выполнил три параллельных чтения исходников (права, история, UI). Запуск тестов в Devin был отклонён его неинтерактивными разрешениями; тесты фактически запустил Codex. Codex проверил исходники, исправил сообщение при сбое загрузки, экранирование счётчиков и закрытие тестовых соединений; выполнил браузерную приёмку. Согласие трёх обзоров не считалось доказательством прохождения тестов.

## Продолжение

Следующий содержательный шаг — сверка кафедрального видеокаталога с учебным планом и заполнение подтверждённых соответствий. Не подставлять общий архив и не придумывать записи для снятия блокировки. Реальные аккаунты шести ординаторов, назначение преподавателей, центральный хостинг и выпуск Tilda остаются отдельными задачами.
