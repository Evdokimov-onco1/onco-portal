## Последнее поручение

Владимир сначала попросил отдельную тестовую версию №2 без изменения старых страниц, затем уточнил: архивировать весь прежний сайт без удаления/потери блоков и сделать текущую версию основной, чтобы пользователи начали тестирование. Последнее поручение имеет приоритет. До замены требуется полный архив и редакторский доступ. Частичный HTML-снимок не закрывает архивирование.

## Состав готового кандидата

## Что проверено

- CDN CSS, JS и JSON, а также Word M05: скачанные файлы точно совпадают с локальными по SHA-256.
- В браузере первый год показывает 34 модуля, второй — 27; открываются M01 и M05; вкладки и ссылка на Word используют закреплённую сборку.
- Исходный комплект проходит `verify_handoff`: 61 модуль, 633 вопроса, 131 контрольная сумма.
- Основная ветка и Tilda в ходе подготовки не изменены. Runtime прежних страниц остался прежним.
