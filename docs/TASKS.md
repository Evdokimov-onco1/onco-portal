## P1 — Сохранение прогресса

Определить модель состояния: пользователь, модуль, раздел, версия материала, результат теста. Поздний handoff предлагал сначала хранение в браузере, затем общий приёмник; это предложение, не выполненная функция.

Готово, когда после перезагрузки восстанавливаются согласованные отметки; пользователи не видят чужой прогресс; смена устройства и очистка браузера имеют заранее описанное поведение; результат не помечается полученным преподавателем без подтверждения.
