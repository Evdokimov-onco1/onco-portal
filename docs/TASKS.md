# Очередь продолжения

Основание — прямое поручение Владимира от 22.09.2026. Статусы ниже описывают работу, которая остаётся после подготовки handoff. Ответственный и срок выбираются участниками; здесь они не назначены.

## P0 — Довести новую версию до ординаторов

Сверить тестовые страницы, учесть восстановленные локальные исправления, согласовать релиз и подключить новую версию через обычную навигацию двух учебных групп.

Готово, когда: оба года доступны обычному участнику своей группы; M01/M24/M33/M46/M61 и Word открываются; тесты показывают ответы и источники; календарь и практика работают; нет ссылок на старый банк; сохранён рабочий откат. Проверки телефона и компьютера зафиксированы. Код на GitHub без проверки Tilda не закрывает задачу.

## P1 — Разделы внутри модуля

Разделить длинную ленту на читаемые вкладки или шаги: лекция/чтение, задачи, устный разбор, тест, практика, инструменты, чек-лист. Готово, когда всё существующее содержимое доступно, прямые ссылки сохраняют смысл, действия понятны на телефоне и с клавиатуры, переходы не сбрасывают незавершённый тест без понятного поведения.

## P1 — Сохранение прогресса

Определить модель состояния: пользователь, модуль, раздел, версия материала, результат теста. Поздний handoff предлагал сначала хранение в браузере, затем общий приёмник; это предложение, не выполненная функция.

Готово, когда после перезагрузки восстанавливаются согласованные отметки; пользователи не видят чужой прогресс; смена устройства и очистка браузера имеют заранее описанное поведение; результат не помечается полученным преподавателем без подтверждения. До общего приёмника не обещать межустройственную синхронизацию.

## P1 — Точные видеоссылки для 61 модуля

Начать с [реестра видеоссылок](VIDEO_LINKS.csv). Он извлечён из текущей базы и не является перечнем уже проверенных ссылок. Для каждой записи сопоставить пакет МЮ и конкретное выступление. Исправлять исходный модуль, затем пересобирать JSON.

Готово, когда проверены все строки, есть конкретная запись или явно указан статус «нужен точный адрес», а неизвестные ссылки не выдуманы. Общая страница конференции может оставаться только с ясной подписью о том, что это общий архив.

## P2 — Общий приёмник результатов

Выбрать владельца, хранилище, идентификацию, минимальные данные, обработку ошибок, подтверждение сохранения и отчёт преподавателю. Сейчас data-results-url пустой; существующий no-cors POST не подтверждает запись. Данные реальных ординаторов не хранить в публичном GitHub.

## P2 — Завершение образовательного раздела

Стартовая `/ordinatura`, итоговая аттестация, ссылки на лекции сотрудников кафедры, содержательная приёмка преподавателями. Макеты первых двух есть в архиве руководителя. Каждую задачу оценивать отдельно; сроков в handoff нет.

## Шаблон задачи или PR

Цель; основание; границы файлов; ожидаемое поведение; что проверено; что ещё не проверено; влияние на Tilda; способ отката. Для медицинской правки дополнительно источник и преподаватель, принявший содержание.
