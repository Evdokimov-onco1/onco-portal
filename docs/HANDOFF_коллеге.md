## Что готово и что пока является планом

В **локальном пилоте** (`feat/module-completion`): клинические ответы, семинар, TB, тест ≥70%, логбук преподавателя и **двустороннее завершение модуля** (см. [MODULE_COMPLETION.md](MODULE_COMPLETION.md)). На **Tilda и в закреплённой сборке №2** этого по-прежнему нет — не путать с продакшеном.

Пока **вне пилота**: шесть реальных ординаторов, боевая авторизация, центральный хостинг, публикация Tilda/`main`, полный видеоаудит (46/61 модулей без кандидата лекции). OSCE для завершения **не обязателен** (решение Владимира 10.10.2026).

Видео на сайте есть: [50 карточек](audit-2026-10-10/FACULTY_VIDEO_CATALOGUE.csv). Тематические привязки предварительные. [Матрица 61 модуля](audit-2026-10-10/MODULE_READINESS.csv) и [63 занятия](audit-2026-10-10/TEACHING_PLAN.csv) помогают распределить работу. Лектор календаря не становится автоматически проверяющим семинара.

## Запуск на своём компьютере

```sh
git clone https://github.com/Evdokimov-onco1/onco-portal.git
cd onco-portal
git fetch origin
git switch feat/module-completion
python3 tools/verify_handoff.py
python3 -m pilot.server --port 8789 --db /absolute/private/path/pilot.sqlite3
```

Пилот: http://127.0.0.1:8789/ — демо-логины в [MODULE_COMPLETION.md](MODULE_COMPLETION.md). **Не пересоздавать БД** без необходимости; для статики старого движка по-прежнему `python3 -m http.server 8787` и `/dev/` (история выпусков ниже).

## Совместная работа

- Согласуйте одну задачу и ответственного, создайте свою ветку от актуальной рабочей базы. Не редактируйте вдвоём один участок без договорённости.
- В PR укажите поведение до/после, проверку, ограничения и влияние на Tilda. Медицинские изменения принимает профильный преподаватель.
- Последнее поручение Владимира заменяет прежнее ограничение: весь старый сайт требуется сохранить в проверенном архиве, затем сделать текущую версию основной. До архива не изменять действующие блоки и навигацию. Сохранить все информационные блоки и материалы при переключении.
- Для №2 предусмотрены новые `/ordinatura-v2-1` и `/ordinatura-v2-2`. До публикации проверить отсутствие занятых адресов и настроить доступ соответствующих учебных групп. Не публиковать закрытую копию без проверки доступа.
- Не сливайте текущий runtime в `main` ради теста: прежние страницы читают `@main`. Публикация №2 использует закреплённый commit, поэтому merge для неё не нужен.
- GitHub collaborator — отдельный доступ от Tilda. На последней проверке редактор Tilda ограничен сообщением об истёкшей опции «Сотрудники» владельца; API-чтение работает, публикация через него не подтверждена.
- Ключи, списки ординаторов и результаты не коммитить. Шесть участников найдены в частном плане ротаций; их аккаунты назначаются штатно отдельно.
