# Коллеге — с чего начать

1. Откройте [полную передачу](HANDOFF.md): она объясняет, что уже сделано и что осталось.
2. Скачайте ветку `handoff/2026-10-04` и выполните [быстрый запуск](DEVELOPMENT.md). Всё для текущей сборки включено в репозиторий.
3. Проверьте [очередь задач](TASKS.md). Сначала новая версия для ординаторов; затем разделы модуля, прогресс и конкретные видео.
4. Выберите с Владимиром одну задачу, заведите свою ветку и PR. Доступ GitHub не заменяет редакторский доступ Tilda.
5. Перед слиянием учтите, что main читается тестовым сайтом. Основные страницы меняются по [процедуре выпуска](RELEASE.md) после отдельной приёмки.

База: 61 модуль, 633 вопроса, 12 виртуальных пациентов, 12 OSCE, 8 Tumor Board, 63 календарных занятия. Содержимое медицинских материалов в этом пакете не переписывалось.

Подробные прежние записки от 14 и 22 сентября сохранены в [истории](HISTORY.md). Текущий пакет дополняет их проверенными исходниками и инструкцией запуска.
