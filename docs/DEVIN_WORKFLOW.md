# Devin: выполнение задач ONCO

Рабочий процесс на Mac Владимира, 10.10.2026. Codex ставит задачу, Devin реализует ограниченную часть, Codex проверяет diff, тесты и браузер. Подключение CLI не означает готовность сайта или наличие расхода в конкретном счётчике подписки.

## Как запускать следующую задачу

1. Проверить `astra-preflight devin` с доступом к сети. `authenticated=true` подтверждает авторизацию, но не квоту и не выполнение задачи.
2. Создать отдельную копию/ветку от принятого commit; определить разрешённые файлы, критерии приёмки и запрет менять медицинскую базу без основания. Секреты, реальные профили и ответы не передавать.
3. В новой папке пройти штатный диалог доверия Devin. Не отключать проверку доверия.
4. Передать файл задания внутри рабочей папки через `--prompt-file`. Использовать `--permission-mode accept-edits`. Неинтерактивный режим останавливает команды, требующие подтверждения: тогда продолжить точную сессию через `-r <session>` в интерактивном режиме. Не включать автоматическое разрешение всех инструментов ради обхода остановки.
5. Сохранять ID сессии, перечень изменённых файлов и фактические ошибки. Готовность определять по файлам и проверкам, а не по сообщению агента или доле квоты. Если исполнитель затягивает задачу, сузить её; законченные изменения сохранять.
6. Codex проверяет код и запускает тесты отдельно; браузерная приёмка выполняется на локальной копии. После приёмки — отдельный PR. Main и Tilda не меняются автоматически.

## Первая функция ONCO

Задача: полный банк вопросов выбранного модуля, порог 70% до округления, повторная попытка; общая выборка остаётся тренировкой. База: `fc269d47bba20e9c61a6010cf42dc31516a8b441`, ветка `feat/module-test-70`. Реализацию JS и стили начал Devin SWE-2 High в сессии `glamorous-brook`; приёмка и GitHub — Codex. Подробности результата и ограничения: [MODULE_TEST_70.md](MODULE_TEST_70.md).

Первый неинтерактивный проход остановился на подтверждении команды. Интерактивное продолжение изменило runtime; подготовка тестов затянулась и была остановлена. Затем дано ограниченное задание на файлы без исполнения команд. Это известное ограничение процесса; общий запускатель ещё не обеспечивает полностью автономное исполнение произвольной задачи.

CLI запускается из установленного приложения Devin. Историю можно продолжить командой `devin -r glamorous-brook`, если CLI доступен в PATH; иначе использовать установленный бинарный файл приложения. Приватные журналы остаются на Mac и в GitHub не публикуются.
