# Последовательные модули и ответы по вопросам — 13.10.2026

Поручение пользователя: шкала прогресса, закрытые серые модули с замком до прохождения предыдущих; отдельное поле для каждого вопроса клинической задачи; свободный ответ для каждой станции OSCE.

- Каталог показывает завершённые модули и шкалу года. Модуль — шкалу выполнения существующих шести критериев подготовки. 100% подготовки не обозначает итоговый зачёт: завершение требует действующего подтверждения преподавателя.
- Внутри каждого года порядок по номеру модуля. Первый модуль доступен сразу; каждый следующий доступен, только если все предыдущие имеют актуальный итоговый зачёт. Начало второго года независимо от первого. Вернувшийся на доработку либо устаревший зачёт вновь закрывает следующие модули. История и черновики в БД сохранены, роли и назначения не меняются. Преподавательский доступ сохраняется.
- Сервер проверяет замок на чтении модуля, практики/прогресса, собственных ответов/попыток по ID, сохранении черновиков, отправке решений, отметках ресурсов, тестах и заявке на зачёт. Список возвращает только метаданные и собственный статус. Прямая ссылка показывает объяснение блокировки, не форму входа.
- Нумерованные вопросы исходного задания получают самостоятельные поля; ненумерованный общий вопрос — одно поле. Ответы сохраняются атомарно прежним API как структурированная строка onco-case-answers/v1. Преподаватель и история показывают читаемый текст. Старый общий черновик сохраняется в первом поле; остальные пусты. Старые обычные ответы остаются читаемыми. Медицинские исходники/версии не меняются.
- Каждая станция OSCE раскрывается отдельно и имеет собственную форму, черновик, отправку и историю. Сохранение одной не теряет локальные правки другой. OSCE остаётся необязательным и не входит в критерии открытия следующего модуля.
