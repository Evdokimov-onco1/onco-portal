# Источники и версии

## Цепочка сборки

1. `archive/supervisor-package-v4/ONCO_RESIDENCY_PORTAL_DATA_V3_INTERACTIVE.json`: база концепции МЮ, модули, библиотека, VP/OSCE/TB.
2. `sources/stage6/Tilda_Банк_тестов_FINAL_v34.html`: канонический банк v34, 61 тема и 633 вопроса.
3. `sources/stage6/М-*.md`: блоки чтения, задачи, устный разбор и чек-листы, ранее извлечённые из Word.
4. `sources/stage6/index.html`: 63 календарных позиции, лекторы и разделы.
5. `modules/`: 61 Word-модуль и календарь, на которые ссылается портал.
6. `tools/build_data.py`: собирает `data/orp-data.json`; `date` равна дате запуска.

Сборка не требует внешней папки stage6 и конвертера с компьютера Владимира. Для будущего изменения Word потребуется согласованное обновление соответствующего Markdown и проверка извлечения по оригиналу.

## Целостность

Хэши исходников, Word и архива: `sources/manifest.sha256.json`. Сводная команда `python3 tools/verify_handoff.py` проверяет их, структуру базы и воспроизводимость сборки. Проверка файла по хэшу не доказывает достоверность медицинского содержания. Новую клиническую редакцию принимать отдельно и фиксировать её происхождение.
